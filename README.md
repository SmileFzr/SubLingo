# SubLingo · 双语字幕

**一个浏览器插件（不是独立程序）** —— 抓取视频网站自身的字幕，实时逐句翻译并叠加成双语字幕，读起来比平台自带的机翻更顺。

> 原项目为 YouTube 专用（youtube-subtitle-translator），v3 起重构为多站点引擎。

## 🚀 主要功能

* **实时双语字幕**：上行译文、下行原文，一次看懂。
* **多站点适配**：按站点 DOM 结构适配 + 通用探测 + 原生字幕轨道，三级降级，尽量不漏。
* **样式预设**：影院 / 课堂 / 极简 / 高对比，一键切换，参数实时生效。
* **精细调节**：字号、最多行数、底色不透明度、文字色、底色色值、是否显示原文。
* **全屏可用**：字幕层会跟随进入全屏容器（旧版在全屏下会消失）。
* **拖拽定位**：按住 **Alt** 拖动字幕，位置按比例记忆，换分辨率、切全屏都不会跑位。
* **本地字幕**：加载 `.srt` / `.vtt`，按播放进度对齐翻译——站点本身不提供字幕时也能用。
* **导出 SRT**：把看过的双语字幕导出为标准 `.srt`，可直接二次利用。
* **样式隔离**：字幕层跑在 Shadow DOM 里，不受站点 CSS 污染，也不会污染站点。

## 🎬 支持站点

| 站点 | 字幕来源 | 状态 |
| --- | --- | --- |
| YouTube | 站内 CC（`.ytp-caption-segment`） | ✅ 原生适配 |
| 哔哩哔哩 | 站内 CC（`.bpx-player-subtitle-panel`） | ✅ 原生适配 |
| Twitch | 站内 CC 容器 / 字幕轨道 | ✅ 有字幕时可用 |
| Kick | video.js 字幕层 | ✅ 有字幕时可用 |
| TikTok | 站内字幕 DOM（不稳定）/ 本地文件 | ⚠️ 多数为硬字幕，见下 |
| Vimeo / Dailymotion / niconico / 爱奇艺 / 优酷 / X / Facebook / Coursera | 通用探测 + 轨道 | ⚠️ 视站点而定 |
| 其它任意网站 | 点弹窗里「此站启用」授权后注入 | ⚠️ 视站点而定 |

**关于硬字幕**：TikTok、Kick、Twitch 上大量内容的字幕是"烧"在画面像素里的，DOM 中拿不到文本，任何读取 DOM 的插件都无能为力。这类视频有两条出路：

1. 用弹窗里的 **本地字幕** 加载 `.srt` / `.vtt`；
2. 后续版本接入画面 OCR（尚未实现）。

## 🛠️ 安装

1. 下载本仓库（Code → Download ZIP）并解压。
2. 浏览器打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 打开右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后的文件夹。
5. 打开视频页，点扩展图标调样式。

## 🧭 使用提示

* 视频需要**先开启站点自带字幕**（YouTube 的 CC、B 站的字幕按钮），插件才有文本可抓。
* 状态条会显示当前字幕来源：`站内字幕已接管` / `原生字幕轨道` / `本地字幕文件` / `暂未检测到字幕源`。
* 换视频后如果没反应，点一下 **重新检测字幕**。
* 弹窗里所有调整都是**实时生效**的，不需要点"应用"。

## ⚠️ 翻译接口说明

使用 `https://translate.googleapis.com/translate_a/single`（Google 翻译非官方公共接口），免费、无需密钥，但不保证长期可用；请求过多时会被限流，插件内置了重试与原文兜底。
